This directory contains helper "libraries" allowing the GenIStreamC tutorial
example to easily export acquired data into the BMP/PLY formats.

The helpers are in particular:

SimpleBMP - https://github.com/vallentin/SimpleBMP
hapPLY - https://github.com/nmwsharp/happly

Please check the provided links to obtain the entire repositories and/or check
the copyright & license information. The respective licenses are also copied
in this directory for convenience.
